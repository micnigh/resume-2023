# Quick start

```sh
# first time
pnpm install

pnpm dev
```

# Testing

Run Playwright tests:

```sh
# Run all tests
pnpm test

# Run tests in UI mode (interactive)
pnpm test:ui

# Run tests in debug mode
pnpm test:debug
```

The tests will automatically start the dev server if it's not already running.
